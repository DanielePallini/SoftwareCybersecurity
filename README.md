## Descrizione del Progetto
Progettazione e implementazione di un software di gestione di una blockchain Ethereum per il tracciamento del carbon footprint di una filiera alimentare tramite l’esecuzione di smart contracts sviluppati in Solidity. 
Il progetto include un'analisi approfondita riguardo la resistenza agli attacchi e una valutazione del rischio durante la fase di progettazione per garantire la sicurezza e l'affidabilità del sistema.

## Project Description
Design and implementation of a software for managing an Ethereum blockchain to track the carbon footprint of a food supply chain through the execution of smart contracts developed with Solidity.
The project involved thorough analysis regarding the resistance to attacks and risk assessment during the design phase to ensure the system's security and reliability.
